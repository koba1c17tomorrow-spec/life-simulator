# P3-1 方向別の関係と相性

旧relationsは削除せず、PCから人物への親密さ/信頼の正本・既存イベント互換投影とする。旧romanceも保持するが、NPCの内心に複製しない。新しいrelationshipModel(version1)は方向別の好意/信頼/親密さ/敬意/恋愛的関心を持ち、欠落は導入時に埋めない。

PC→NPCの親密さ/信頼は旧relationsを参照し、重複保存しない（新edge内はnull）。それ以外の不明値はnull。新しい交流から中立50を基準とする観測後指標を開始し、過去の本当の気持ちを復元したとは扱わない。NPC→PCおよびNPC同士は別のedgeで更新する。恋愛的関心は通常の交流では自動加算しない。

相性は既存の性格/価値観、活動（会話/同席）、健康、既知の関係の蓄積から方向別に評価する。PCの傾向は既存traits/生活方針だけを用いる。改善・悪化・不変は条件から決まり、今回の交流自体は乱数を消費しない。同席の苦手な物静かな相手、体調の悪い相手、価値観の違い等で反応が変わる。固定の好転ボーナスを別経路で追加しない。

UIの数値は「あなたの気持ち」と明記し、NPCの内心は数値も内部スコアに基づく自動ラベルも表示しない。実際の応対から得た態度だけを保存・表示する。未交流なら未観測。故人への新規交流は拒否し、既存edgeは保持する。

保存では人物参照・重複方向・軸の範囲/null・観測年月を検証して不正値を拒否する。旧fixture・旧relations・NPC履歴を変更せず、過去のNPC感情を推定しない。既存の月次接触・贈り物等はPC側互換投影だけを変え、NPC側の感情へ無条件反映しない。
