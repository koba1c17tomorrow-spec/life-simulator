# Life Simulator v3 開発ロードマップ

[ゲーム設計](GAME_DESIGN.md)を段階的に実装する7 Phase・21タスク。品質基準は [受入条件](ACCEPTANCE_CRITERIA.md)、作業規則は [AGENTS.md](../AGENTS.md) を参照する。

## 状態と進め方

- P0-0は本ロードマップ等の文書整備で、以下の21タスクには含めない。PR #1でmainへ反映済み。
- P0-1はPR #2でmainへ反映済み。P0-2は以下に実績を記録し、残る19タスクは未着手。既存の部分実装や旧 `ROADMAP.md` の完了表示は、v3の完了を意味しない。
- 記載順で1タスクずつ進める。依存関係は最低限の技術的前提であり、前段タスクを飛ばす指示ではない。
- 完了状態は「未着手 → 作業中 → 検証待ち → 完了」。停止時は「ブロック中」と理由を記録する。完了には該当する受入条件と検証根拠が必要。
- 主な変更対象は現行ファイルからの候補で、将来モジュール名を確定するものではない。各タスクで合理的に整理し、無関係な機能を先取りしない。
- 作業時には各タスクの実績欄へコミット/PR、実行コマンドと結果、残課題を追記する。分布の係数や目標は観測・根拠とともに決める。
