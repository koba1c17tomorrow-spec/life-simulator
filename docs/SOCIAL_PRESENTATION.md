# P4-3 社会の観測と表示

既存の記録画面に閉じたdetails「社会の様子・知らせ」を追加する。GUI全体の再設計/Issue #9は対象外。SocialPanelはsocialPresentationの公開投影だけを描画し、生の社会軸/NPC actor/非公開世界履歴を渡して表示しない。通常の人生ログの公開経路も維持する。

社会更新/描画だけではPCの知識は増えない。プレイヤーの「知らせを確認（2時間）」操作時、時間予算から2時間を1回消費する。今月確認済み/pending/死亡/社会未導入/時間不足は実行不可。自主行動の月1枠とは別の情報確認であり、同じ月720時間を共有する。保存再開後も今月確認済みを維持し、重複課金/再観測しない。privateやNPCイベントは対象外。公表済み未読社会イベントを古い順に最大8件知る（残りは次回以降）、pcKnowledgeの知得月と既存journalのworldEventIdを保存する。

societyKnowledge.version:1に観測月と6軸の5段階を保存する。内部値0..100は20点幅（100は最上段）で厳しい/やや厳しい/中程度/比較的良好/良好に分類する。これは公表概況から得た粗い評価という抽象化で、取材/統計誤差の精密モデルではない。未観測は「未確認」、観測済みは何か月目の概況かを明示。後の内部変化を自動反映せず、最新の真相と混同しない。内部のprivate協議の内容や存在数は表示しない。

確認済みpublicイベントだけ最新8件を結果として表示。公表された文章、社会軸の実変化、発生月/知った月を別に示す。causeがすべて既知の場合だけ原因のつながりを説明する。PC自身の実選択が既知の原因なら、その選択名を示す。未確認の原因を公開せず「詳しい因果関係は未確認」。無関係なNPCの感情/目標や内部の条件判定値を推測で表示しない。

旧セーブに知識がなければ補完しない。未来の観測月、不正な段階、未対応versionを拒否。保存ファイル自体には内部値も含み、暗号化/改ざん防止の提供とは区別する。fantasy設定/文章はP4-2単体検証までで、ゲーム画面全体のfantasy対応はP5待ち。
