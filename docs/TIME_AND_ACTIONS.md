# P2-2 生活方針・重点行動・時間予算

## 実装前に定義した単位と範囲

月は引き続き1ターン。暦の長短とは別に**30日×24=720時間**をゲームの共通予算とする。精密な時間利用統計ではなく、競合を表す粗いモデル。睡眠240、基礎休息60、家事60、在学140、非退職就業160（parttime80）、扶養する子1人8、病気48、高ストレス24時間を確保する。学業と仕事が併存する場合は両方を計上。生活方針は既存5種類を維持し、対応する学習/交流/健康/趣味/追加休息に24時間を配分する。既存の小さな月次補正をこの24時間の効果と解釈し、別の基礎能力ボーナスを追加しない。義務超過時は予算720まで充当し、超過要求を別記する。自由行動は残時間0として拒否する。

重点行動は勉強・単発仕事・休息の既存活動。低/中/高強度は8/16/32時間、効果倍率1/1.5/2。低強度は既存効果を維持。中/高の勉強費用500/1000円、仕事・勉強は中/高でストレス1/3を追加する。健康20未満は仕事・勉強不可、高強度は健康40以上。資金・健康・時間・年齢・進行停止・当月回数を実行前に確認し、失敗理由を表示する。休息は技能を獲得しない。努力/技能の全面刷新はP2-3。

交流は8時間で自主行動と同じ月1枠。購入は別の月1枠を維持するが同じ予算から2時間を消費する。購入の効果を自主行動として二重適用しない。金融口座間の移動は追加時間を要求しない。

## 月と計画の境界

画面の月は処理済みの月。プレイヤーは次の月（これから開始するターン）の重点行動と強度を計画できる。一回限りの計画を保存し、その月のイベント/選択がすべて解決した時点で実行する。継続的な生活方針とは別。今月の自主行動ボタンは即時実行で、同じ月の計画と共通の枠/時間を使う。計画を設定しただけでは時間や費用を消費しない。

月開始の学年・職業・健康更新後に、その月の義務を一度確保する。前月の在学状態を卒業月に再確保しない。選択待ちの間は月開始効果を繰り返さない。病気・家庭・仕事・イベント後の状態により追加義務を確保し、計画が妨げられれば理由付きblockedとして記録する。確保済み時間は戻さず、同月の方針変更や退職で時間を作り直せない。死亡時は計画を中断し、活動効果なし。計画の意図、結果、実時間、理由を保存し、月が一致する完了済み計画は再実行しない。保存再開時も同じ処理。

旧セーブの時間拡張は任意。インポートで過去時間を復元したふりをしない。次月開始または最初の成功活動で現在の予算を作り、既存lastActionMonth/lastSpendMonthで過去の利用枠を保護する。旧セーブの途中月で過去に消費した詳細時間は不明。既存効果・履歴・pending/queue/scheduledは削除しない。P5-1のシーン時間は未実装。

時間の`legacyBaseline`は旧保存由来の観測であることを示す。以後の新しい月は予算と実消費を記録でき、導入前の消費時間を復元したことにはしない。
