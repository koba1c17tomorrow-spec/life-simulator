# P2-1 人物能力の4層

## 実装する最小モデル

資質は既存の固定 `traits`、基礎能力は既存の `stats.knowledge/sociability` を唯一の正本とする。健康・幸福・資金は能力に混ぜない。専門技能は学習技法・実務・対話の3つだけを導入し、実行した学習・就業・交流で獲得する。既存の基礎能力の成長を技能に再適用しない。技能は採用判定に最大5点の補助として作用する。活動時間・疲労等を含めた全面的な成長/判定刷新はP2-3。

第4層は既存の学歴、資格フラグ、就業月数、職業経歴、実績を参照し、複製しない。評判の値は未記録であり生成しない。NPCについては既存の人物情報を維持し、未知の技能や過去経験は補完しない。自律更新はP3以降。

新規人物の資質は最初は未判明。関連活動の累積から段階的に定性的名称のみを公開する。資質そのものは変化しない。既存セーブで既に表示された資質は隠し直さない。

## 互換性

`capabilities` は任意のversion 1拡張。欠落をインポート時に埋めない。旧状態をそのまま保存し直せる。初めて活動した時点で導入後の観測を開始し、技能指標0は「過去の熟練度は不明」を意味する。過去に技能/資格を取得した事実を推定しない。版、値域、参照元traits、観測開始年月を検証し、不正な拡張は拒否する。乱数は消費しない。

## 初期係数の位置付け

技能は0..100の観測指標。自主活動1単位、月次の在学/非退職就業0.1単位、関連資質は獲得量1.2倍、熟練度に応じ`1-current/100`で逓減する。関連活動3単位を公開の最低観測量とした。実社会の推定値ではなく、初期の明示的なゲーム単位でありP2-3の調整対象。採用補助は(実務+対話)/40、最大5点。基礎能力の既存効果・特性補正は二重適用しない。学校/就業の観測は月開始処理の中に一度だけ置き、選択再開時に反復しない。退職後は就業観測を行わない。

## P2-3更新

上記P2-1の初期式は履歴。現在は[SKILL_GROWTH](SKILL_GROWTH.md)の実時間・健康・疲労・環境の式を適用する。観測値の保存形式は維持し、過去値を新しい時間へ逆算しない。
