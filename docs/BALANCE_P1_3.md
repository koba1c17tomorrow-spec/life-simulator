# P1-3 暫定バランス観測と調整

起点main `638762dfbbeed7bcfb4b8d6de95ab280176cd56c`。調整前に測定し、同じseed/世界/方針の組合せで調整後を再測定した。目標値を先に置いて乱数seedやしきい値を選び直していない。

## 再現条件

```bash
node scripts/balance-study.mjs docs/balance/result.json
```

既存のVite SSRローダーで既存エンジンを実行する。追加依存・外部APIなし。出力には元コミットとruntimePatchを含む。beforeを再現する場合は起点コミットのsrcを使い、afterは対応patchまたはP1-3コミットのsrcを使う。P2以降のsrcで実行した結果をP1-3のafterと混同しない。

- seed候補は `7919 × 1..100`、出生経済3群から最初の2seedずつを採取。最終seed：7919, 15838, 23757, 39595, 71271, 79190。
- 6seed × 5方針 × modern/coastal = **60人生**。全組合せを実行し、方針や世界をseedに固定しない。
- ランダム決断、購入/投資/自主行動なし。6/18/40/65歳の生存者を記録し、死亡時点の純資産も記録。年齢別の分母nはJSONに保存。
- 再起は同じ6seed×2世界×2状態=**24合成ケース**。25歳、現金2万円/債務50万円、生活basic、過去就労12月という明示した検証状態から15年進行。実在の旧セーブとは主張しない。
- 量的比較は補間分位点。元の全行、年齢別、出生条件/方針/世界別のn・最小・p10/p25/中央値/p75/p90・最大・平均は [before](balance/p1-3-before.json) / [after](balance/p1-3-after.json) に保存。

## 観測と採用した最小変更

40歳の知識は中央値99.97、65歳の知識・社交性もほぼ100に収束していた。自然成長だけでなく、反復イベント等の正の加算の累積が原因。18歳の知識p90は約59.86で、学齢期の基礎帯は保たれている。そこで既存0〜100尺度の60以下・負の効果を維持し、60超の正の知識/社交性加算だけ `(100-current)/40` 倍へ逓減する。既存の100という尺度を変更せず、新しい一律資産上限を設けない。

昇進は従来の全段階60月から `60 + 24×現在level` 月へ変更。初回昇進と初任給は維持し、上位ほど長い経験を必要とする。給与の基準額、税、生活費、資産・債務の既得値は変更しない。旧保存の能力・役職・資産を読み込み時に引き下げず、今後の進行だけに新ルールが作用する。乱数の追加消費はないが、能力に依存する合否等は旧ルールと異なり得る。

### 再起ケース

低所得ケースは両版とも40歳就労11/12、純資産正6/12。失業ケースは両版とも就労12/12だが、純資産正は12/12→11/12。負債から抜けられない個別ケースがあり、再就職だけで財政回復を保証しない。最低所得・給付・債務整理を削らず、低所得者を一律に困窮させる調整は行わなかった。

## 検証と限界

`tests/inflation.test.ts`で逓減、低能力帯/負の効果の維持、昇進期間、既得セーブ非変更を検証。P1-3の全テスト/ビルドの結果はROADMAP_V3に記録する。P2-1の4層やP2-2の時間予算をこの調整へ混ぜていない。新しい能力値の目標分布は固定せず、引き続き観測する。
