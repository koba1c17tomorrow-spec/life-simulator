# 人生シミュレーション（v0.3 試作版）

個人用の日本語ブラウザ人生シミュレーションです。React / TypeScript / Viteで構成され、プレイ中のAI利用や外部サーバーは不要です。

## Windowsでの起動

1. [Node.js](https://nodejs.org/) のLTS版をインストール
2. GitHubの緑色の **Code** → **Download ZIP** でダウンロードして解凍
3. 解凍した `life-simulator-main` フォルダを開く
4. エクスプローラーのアドレスバーに `powershell` と入力してEnter
5. 以下を実行

```powershell
npm install
npm run dev
```

6. 表示される `http://127.0.0.1:5173/` などのURLをブラウザで開く

起動したターミナルを閉じるとゲームも停止します。プレイ記録はブラウザのlocalStorageに保存されます（ブラウザデータ削除で消えるため注意）。

## テスト

```powershell
npm test
npm run build
```

## 実装済み

- 月単位の自動進行・停止・速度調整
- 最新が先頭の人生ログ
- 複数イベントと選択待ち中の月内処理再開
- シード付き乱数とブラウザ内セーブ
- JSON定義の架空現代世界イベント
- ステータス・日々の優先事項・月1回の自主行動
