# 人生の記録 — v2.0 beta

文章中心の日本語ブラウザ人生シミュレーター。出生条件・資質・学校・仕事・家族・健康・偶然が積み重なり、一人の人生を月単位で進めます。React・TypeScript・Vite製。プレイ中の生成AI・外部API・アカウントは不要です。

## 起動

Node.js 24 LTS（検証版24.19.0）とnpmを使用します。

```bash
npm ci
npm run dev
```

`package.json` があるフォルダで実行してください。開発サーバーはローカルで動作します。停止はCtrl+C。固定ポートで起動する場合は `npm run dev -- --port 5173 --strictPort`。

## 遊び方

- 「再生」で月次進行。「＋1か月」で一月ずつ確認できます。
- 生活方針は「家族・友人」「健康管理」「自己研鑽」「趣味」「休息」。年齢ごとの自然成長・衰退に約10%の小さな補正を与え、出来事や交流にも影響します。
- 普段の生活は自動進行。部活・進路・就職・交際・結婚・家族計画などの判断では停止します。「一時的に閉じる」で周囲の情報を確認できます。
- ランダム選択モードでは重大な決断も自動処理されます。自分で人生の方向を決めたい場合は解除してください。
- 「家計・支出」で外食・贈り物・旅行・趣味・娯楽、教材・習い事・資格・訓練・進学準備、家電・スマートフォン・住居・健康管理を購入できます。年齢・所持金・買い替え間隔・月1回の購入制限があります。
- 貯蓄・投資・売却・返済、生活水準の変更、債務整理も家計画面で行います。投資は値下がりします。借金額だけで人生は終了しません。
- 「進路・仕事」で成績・進路・学歴・職業・経験・採用率を確認。「人物」では相手自身の暮らしや人物同士の関係も表示します。
- 「年表・振り返り」には節目、実績、人生の結末が残ります。
- 新しい人生ではワールド・性別・性的指向・乱数シードを指定できます。同じワールド・シード・属性設定・操作列で同じ結果を再現できます。

## セーブ

自動保存キー `life-sim-modern-v1` を維持し、v1の不足フィールドは補完します。旧方針 `study/social/health` は新名称へ移行します。元の出生シードがない旧セーブは「不明」と表示し、進行中の乱数状態は維持します。

3スロットは自動保存とは別の保管場所です。JSONを端末へ書き出してバックアップできます。不正な自動保存はそのまま保持し、自動上書きを止めます。ブラウザデータ削除・別端末への移動では保存は引き継がれません。更新前にもJSONバックアップを推奨します。旧ルールと新版ルールの結果が同じになる保証はありません。

## 検証

```bash
npm test             # 単体・統合・100シード人生シミュレーション
npm run build        # TypeScript型チェックと本番ビルド
npm run test:long    # 長期検証だけを実行（約1〜2分）
npx playwright install chromium
npm run test:browser # PCとスマートフォン幅の10ケース
```

システムChromiumがあるLinuxでは `CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:browser` を使えます。ブラウザのダウンロードはその場合不要です。Playwrightテストは専用ブラウザコンテキストを使い、通常のプレイ用セーブを変更しません。

検証の実測と限界は [VALIDATION.md](VALIDATION.md)、実装対応表は [ROADMAP.md](ROADMAP.md)、次回の注意点は [NEXT_TASKS.md](NEXT_TASKS.md) を参照してください。

## 開発用ファイル

- `src/engine.ts`：月次オーケストレーション・決断・セーブ移行
- `src/balance.ts` / `src/origins.ts` / `src/traits.ts`：成長・出生条件・特性
- `src/economy.ts` / `src/education.ts` / `src/health.ts`：家計・教育・健康と老後
- `src/careers.ts` / `src/social.ts` / `src/relationships.ts`：求人とNPCの人生
- `src/eventRules.ts` / `src/content.ts`：条件・成功率と説明・JSON検証・ワールド読込
- `src/journal.ts` / `src/saves.ts`：一意なログ・保存スロット・入出力
- `src/main.tsx` / `src/panels.tsx`：画面
- `public/worlds/*/manifest.json` と `events.json`：ワールドと出来事

イベントは年齢を**月数**で記述します。`requires` で能力・特性・職業・地域・履歴フラグなどを指定し、選択肢に成功失敗の効果・フラグ・遅延結果を設定できます。`validateEvents` とテストを通してください。新ワールドは `src/content.ts` の一覧に登録し、公開ディレクトリへmanifestとイベントを追加します。

## モデルの範囲

これはプレイ可能なベータ版です。税・年金・奨学金・債務整理・病気・性的指向・家族形成はゲーム用の簡易モデルであり、現実の制度や統計の再現ではありません。兄弟姉妹は出生条件の人数、NPC側の子どもは家庭内人数として扱います。現代・海辺の町は同じ制度を共有し、地域・出来事が異なります。親の特性への30%の抽選バイアスはゲーム用の表現です。実在する遺伝の再現やNPC側の子ども一人ずつの家系シミュレーションは扱いません。全人生の網羅的な手動プレイや全ブラウザ・スクリーンリーダーでの検証は行っていません。
